**Status:** PRE-REGISTERED

**Hash sidecar:** artifacts/01/decisions.sha256
**Machine-readable source:** configs/protocol.yaml

## Scope

These decisions are frozen before any reconstruction, before any mesh is produced, and before any evaluation number exists. Segment selection uses the criteria below, never a metric outcome.

## Segment Selection

- Candidate: `2013_05_28_drive_0000_sync` (provisional for calibration; final selection in Phase 2).
- Criteria: lowest median dynamic-pixel fraction over a 120-frame window; at least 120 contiguous frames present in image_00, image_01, velodyne_points, and poses; residential or suburban route preferred.
- Tie-break: fewer dynamic object instances, then longer contiguous pose coverage.
- Forbidden: selecting by reconstruction error, metric value, or visual mesh quality.

## Frame Window

- 60–120 consecutive frames.
- At least 30 evaluated frames.
- At least 20 000 valid rays per frame.
- Policy: the first contiguous block satisfying the all-stream intersection; no per-frame cherry-picking.

## Metrics and Thresholds

| Item | Frozen value |
|---|---|
| τ values | 0.05 m, 0.20 m (primary), 0.50 m — true Euclidean distance |
| Primary metric | Range RMSE over hits, micro-averaged over pooled rays |
| Paired reporting | Ray recall and coverage on every accuracy row |
| Secondary metrics | CD-L1 (metres), F-score at τ = 0.20 m |
| Aggregation | Micro (pooled) headline plus macro per-frame ± std |
| Distance buckets | [0,20), [20,40), [40,50] primary; (50,60] secondary |
| `r_min` | 1.5 m |
| `t_max` | 60 m |
| Image margin | 5 px |
| Occlusion | GT-only flag; flagged points reported separately, never using reconstructed depth |

## Exclusions

- Dynamic classes: car, truck, bus, motorcycle, bicycle, person, rider.
- Ego ROI in Velodyne coordinates: `|x| < 2.5 m`, `|y| < 1.2 m`, `-2.0 < z < 0.3 m`.
- Range below 1.5 m and above 60 m.
- Behind-camera or outside-image rays using the 5 px margin.

## Change Policy

Any change to these values requires a new hash, a documented rationale, and a new run ID. Thresholds are never relaxed to make a result pass.

1. `src/hls/common/prereg.py`:
   - `sha256_decisions(path: Path) -> str`: SHA-256 of the exact file bytes.
   - `freeze_decisions(decisions: Path, protocol: Path, sidecar: Path, now_utc: str | None = None) -> dict`:
     - Read `decisions` text.
     - Replace the line matching `**Frozen at (UTC):** ...` with `**Frozen at (UTC):** <ISO-8601 Z>` using `datetime.now(timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ")` unless `now_utc` is supplied.
     - Write the file back with UTF-8 and a trailing newline.
     - Compute `decisions_sha256` and `protocol_sha256`.
     - Write the sidecar in `sha256sum` format: `<decisions_sha256>  docs/decisions.md\n`.
     - Write `<sidecar>.json` with `schema_version: 1`, `frozen_at_utc`, `decisions_path`, `decisions_sha256`, `protocol_path`, `protocol_sha256`.
     - Return the JSON object.
   - `verify_decisions(decisions: Path, sidecar: Path) -> dict`: read the first 64 hex characters of the sidecar, recompute, and return `{"ok": bool, "expected": str, "actual": str, "frozen_at_utc": ...}`. Missing sidecar raises `FileNotFoundError`; malformed sidecar raises `ValueError`.
   - The hash is over the file **after** the timestamp substitution, never over a pre-timestamp copy.

2. `src/hls/commands/prereg.py`:
   - `register(subparsers)` adds `prereg` with subcommands `freeze` and `verify`.
   - `freeze`: `--decisions docs/decisions.md`, `--protocol configs/protocol.yaml`, `--sidecar artifacts/01/decisions.sha256`; prints the hash and timestamp; returns 0.
   - `verify`: same path flags; prints `OK <hash>` or `MISMATCH expected=... actual=...`; returns 0 on match, 6 on mismatch, 4 on missing/malformed input.
   - `prereg` with no subcommand exits 2.

3. `scripts/03_prereg.py`: wrapper calling `main(["prereg", *sys.argv[1:]])`.

4. Tests:
   - `sha256_decisions` changes when one byte changes.
   - `freeze_decisions` replaces PENDING with a UTC timestamp, writes the sidecar, and `verify_decisions` returns `ok is True`.
   - Tampering with one character after freezing makes `verify` exit 6 and print `MISMATCH`.
   - Deleting the sidecar returns exit 4.
   - `freeze` is deterministic when `now_utc` is injected.
   - The sidecar JSON records both the decisions and protocol hashes.

5. Run the real freeze after the tests:
   `bash scripts/hls.sh hls prereg freeze --decisions docs/decisions.md --protocol configs/protocol.yaml --sidecar artifacts/01/decisions.sha256`

1. `src/hls/data/acquire.py`:
   - `class AcquisitionError(RuntimeError)` with an `exit_code` attribute (7 for missing/invalid official component, 8 for unsafe archive, 4 for missing/impossible link sources).
   - `safe_extract(archive: Path, dest: Path, allow_prefixes: Sequence[str], *, max_bytes: int = 120_000_000_000, max_members: int = 1_000_000, disk_factor: float = 2.5, estimated_extract_bytes: int | None = None, stream: bool = False) -> dict`:
     - Support `.zip`, `.tar`, `.tar.gz`, `.tgz`.
     - For every member: normalize with `PurePosixPath`; reject absolute paths, any `..` part, symlinks, hardlinks, device files, FIFOs. Reject before writing anything.
     - Enforce cumulative uncompressed size ≤ `max_bytes` and member count ≤ `max_members`; abort with `AcquisitionError(exit_code=8)` before extraction if exceeded.
     - **Disk guard must be allowlist-aware.** Pre-scan the archive central directory / member table and sum the uncompressed sizes of members that will actually be written (allowlisted matches). Compute `required = disk_factor * (estimated_extract_bytes if given else allowlisted_bytes)` and require `shutil.disk_usage(dest).free >= required`. This avoids the 2.5×-whole-archive abort when only one sequence is extracted from a large shared archive; it never weakens the guard for a genuinely full disk. Abort with exit 8 and a message naming required/free/allowlisted bytes.
     - **Prefix matching (must not skip valid members):** for every member path, try candidates in order: (a) the path unchanged, (b) the path with exactly one leading wrapper segment stripped (for `KITTI-360/calibration/...`, `<seq>/data_2d_raw/...`). Accept the first candidate `rel` such that `rel == p or rel.startswith(p + "/")` for some `p` in `allow_prefixes`, and write to `dest/rel`. Never strip a segment that is itself the first segment of an allow prefix: an archive whose root is `data_2d_semantics/` with members `data_2d_semantics/train/<seq>/...` matches candidate (a) and must not be stripped to `train/<seq>/...` and skipped. Record the chosen mapping (`member -> rel`) in the returned `mapping` for auditing.
     - Extract only accepted members; count every other member in `skipped_members` (do not write it).
     - Still reject any member whose resolved destination escapes `dest` (use `PurePosixPath(rel).parts` and reject `..`/absolute again after mapping).
     - Support streaming mode (`stream=True`): for tar archives, iterate the stream and extract accepted members without staging the archive on disk; for zip, use the existing file. Never require the full archive to be resident when the user chose stream-extract for an all-sequences archive.
     - Create parents, write with 0644, never follow a symlink in `dest`.
     - Return `{"extracted": [...], "skipped_members": N, "bytes": B, "mapping": {...}, "allowlisted_bytes": B}`.

Verify each target contains the expected `.png`/`.bin`/timestamp content.

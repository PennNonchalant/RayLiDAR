  <action>
1. `src/hls/data/acquire.py`:
   - `class AcquisitionError(RuntimeError)` with an `exit_code` attribute (7 for missing/invalid official component, 8 for unsafe archive).
   - `safe_extract(archive: Path, dest: Path, allow_prefixes: Sequence[str], *, max_bytes: int = 120_000_000_000, max_members: int = 1_000_000) -> dict`:
     - Support `.zip`, `.tar`, `.tar.gz`, `.tgz`.
     - For every member: normalize with `PurePosixPath`; reject absolute paths, any `..` part, symlinks, hardlinks, device files, FIFOs. Reject before writing anything.
     - Enforce cumulative uncompressed size ≤ `max_bytes` and member count ≤ `max_members`; abort with `AcquisitionError(exit_code=8)` before extraction if exceeded.
     - Before extraction, require `shutil.disk_usage(dest).free >= 2.5 * archive.stat().st_size`; abort with exit 8 and a message naming the required/free bytes if not.
     - Extract only members whose normalized path starts with one of `allow_prefixes`; count every other member in `skipped_members` (do not write it).
     - Support archives whose members are wrapped in a top-level directory (for example `KITTI-360/calibration/...` or `<seq>/data_2d_raw/...`): strip one common wrapper prefix before matching, but still reject any member that resolves outside `dest`.
     - Create parents, write with 0644, never follow a symlink in `dest`.
     - Return `{"extracted": [...], "skipped_members": N, "bytes": B}`.
   - `install_staging(staging: Path, root: Path, sequence: str, cameras: Sequence[str], *, policy: str, link_sources: dict[str, Path] | None = None, manifest_path: Path) -> dict`:
     - `allow_prefixes` for the chosen sequence only: `calibration/`, `data_poses/<seq>/`, `data_2d_semantics/train/<seq>/`, `data_2d_raw/<seq>/image_00/data_rect/`, `data_2d_raw/<seq>/image_01/data_rect/`.
     - Extract each archive found in `staging` (sorted by name) into a temporary directory under `staging/_extract` then install into `root` using `shutil.copy2`/`shutil.move` on the same filesystem. Remove the temporary directory after success.
     - If `policy == "reuse_local_after_g1"`, create symlinks for `data_2d_raw/<seq>/image_00/data_rect`, `image_01/data_rect`, `image_00/timestamps.txt`, `image_01/timestamps.txt`, and `data_3d_raw/<seq>/velodyne_points` from `link_sources`. Verify each target exists and contains the expected `.png`/`.bin`/timestamp content. Record `image_provenance: "local_repackaged_1408x376"`.
     - If `policy == "official_data_rect"`, require the extracted official `data_rect` directories; record `image_provenance: "official_data_rect"`.
     - Refuse to create any sequence directory other than `<seq>` under `data_poses`, `data_2d_raw`, `data_2d_semantics/train`, or `data_3d_raw`; list any pre-existing extra sequence directories as `extra_sequences` in the manifest but do not delete them.
     - Require the three official calibration files; if absent, raise `AcquisitionError(exit_code=7)` with the missing filenames. If any forbidden KITTI-raw name is present in the installment paths, raise exit 7 with `KITTI-raw calibration is not accepted`.
     - Verify the readiness report from `run_preflight(...)` has `ok is True`; otherwise raise exit 7 and include the report.
     - Write `manifest_path`:
       ```json
       {
         "schema_version": 1,
         "release": "KITTI-360",
         "source": "https://www.cvlibs.net/datasets/kitti-360/user_login.php",
         "license": "KITTI-360 non-commercial research use",
         "sequence": "<seq>",
         "installed_at_utc": "<UTC ISO-8601>",
         "root": "<root>",
         "image_provenance": "<policy>",
         "archives": [{"name": "...", "bytes": 0, "sha256": "..."}],
         "components": {"calibration": {"files": 3, "bytes": 0}, "...": {}},
         "links": {"<root-relative link>": "<target>"},
         "skipped_members": 0,
         "extra_sequences": []
       }
       ```
       Hash small components' files individually and hash archives; images/semantics record count + bytes + archive hash.
   - `install_staging` must be idempotent: a second run overwrites files deterministically and produces the same manifest except `installed_at_utc`.

2. `src/hls/commands/acquire.py`: `register(subparsers)` adds `acquire` with `--config`, `--staging`, `--root`, `--sequence`, `--policy {reuse_local_after_g1,official_data_rect}`, `--manifest`, `--dry-run`. `run(args)` prints a plan in dry-run mode; otherwise calls `install_staging` and prints the manifest path.

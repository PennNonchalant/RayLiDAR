`src/hls/common/frames.py`:
- `compose(T_A_B: np.ndarray, T_B_C: np.ndarray) -> np.ndarray`: returns `T_A_B @ T_B_C`; assert both are 4×4 and finite.
- `as_homogeneous(mat: np.ndarray) -> np.ndarray`: accepts 3×4 or 4×4, returns 4×4 float64 with `[0,0,0,1]`.
- `invert_rigid(T: np.ndarray) -> np.ndarray`: validate the rotation block with `assert_rotation`, then return `[[R.T, -R.T @ t], [0, 1]]`; must agree with `np.linalg.inv(T)` within `1e-12`.
- `rotation_of(T)`, `translation_of(T)`.
- `assert_rotation(R: np.ndarray, atol: float = 1.0e-6, det_atol: float = 1.0e-12) -> None`: raises `AssertionError` unless `det(R) ≈ +1` and `RᵀR ≈ I`.
- `assert_roundtrip(T_AB: np.ndarray, T_BA: np.ndarray, atol: float = 1.0e-9) -> None`: raises unless `T_AB @ T_BA ≈ I` within `atol`.
- `make_seg_transform(cam_centers_W: np.ndarray) -> tuple[np.ndarray, np.ndarray]`: `cam_centers_W` is `(N,3)`; origin `a_W = median(..., axis=0)`; returns `T_S_W` with identity rotation and translation `-a_W`, and `T_W_S` with `+a_W`.
- `@dataclass(frozen=True) class PoseLookup`: fields `frame_requested: int`, `pose_frame: int`, `delta: int`, `T_W_I: np.ndarray`.
- `pose_lookup(poses: Mapping[int, np.ndarray], frame: int, max_delta: int = 5) -> PoseLookup`: if the exact frame exists use it; otherwise choose the smallest `abs(delta)`, tie-break to the lower pose frame. If the nearest delta exceeds `max_delta`, raise `LookupError` naming the requested frame and nearest delta. Never default to `min(poses)` or frame 0.
- `estimate_ground_z_V(points_V: np.ndarray, radius_m: tuple[float, float] = (5.0, 30.0), z_range_m: tuple[float, float] = (-3.0, 1.0)) -> float`: uses columns 0/1 for horizontal radius and column 2 for z; returns the median z of inliers; raises `ValueError` if fewer than 100 inliers.
- `camera_height(T_V_C0: np.ndarray, ground_z_V: float) -> float`: `translation_of(T_V_C0)[2] - ground_z_V`.

`src/hls/common/calib.py`:
- `@dataclass(frozen=True) class Kitti360Calib`: `T_V_C0`, `T_I_Ck: dict[str, np.ndarray]`, `R_rect: dict[str, np.ndarray]`, `P_rect: dict[str, np.ndarray]`, `K_rect: dict[str, np.ndarray]`.
- `load_calib_cam_to_pose(path)`: parse lines beginning with `image_00:`, `image_01:`, `image_02:`, `image_03:`; each has exactly 12 floats; append `[0,0,0,1]`; return dict keyed by camera.
- `load_calib_cam_to_velo(path)`: exactly 12 floats on non-comment lines; append `[0,0,0,1]`.
- `load_perspective(path)`: parse `P_rect_00`, `P_rect_01` (12 floats, 3×4 + last row) and `R_rect_00`, `R_rect_01` (9 floats, 3×3). Return `(P_rect, R_rect)`.
- `load_kitti360_calib(calibration_dir: Path) -> Kitti360Calib`: load all three files; `K_rect[cam] = P_rect[cam][:3, :3]`; assert focal lengths positive and principal point inside a 1408×376 image; assert `R_rect` orthonormal.
- `rect4(R: np.ndarray) -> np.ndarray`.
- `load_poses(path) -> dict[int, np.ndarray]`: each line `frame r11 r12 r13 tx r21 ... tz` (13 tokens); duplicate frames raise `ValueError`; return `T_W_I`.
- `load_cam0_to_world(path) -> dict[int, np.ndarray]`: each line `frame` + 16 floats; duplicate frames raise.
- `compose_T_W_V(calib, T_W_I)`, `compose_T_W_Ck_rect(calib, T_W_I, cam)`, `compose_T_Ck_rect_V(calib, T_W_I, cam)` exactly as the interface block. `compose_T_Ck_rect_V` must compute both the inverted-chain form and `rect4(R_rect) @ invert(T_V_Ck)`, and assert they agree within `1e-9`.
- Every loader must reject non-finite values and wrong token counts with a message naming the file and line.

Fixture factory in `tests/common/conftest.py`: `make_calib_tree(tmp_path, *, rect_perturbation=0.0, cam1_offset=(0.0, 0.06, 0.0), frames=(0, 2, 4))` writes:

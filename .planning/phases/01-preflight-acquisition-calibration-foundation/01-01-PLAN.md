6. `scripts/hls.sh` (mode 0755):
   ```bash
   #!/usr/bin/env bash
   set -euo pipefail
   ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
   if [[ ! -f "$ROOT/.env.container" ]]; then
     echo "ERROR: $ROOT/.env.container is missing." >&2
     echo "Create it from .env.container.example and set HLS_CONTAINER_RUN_CMD." >&2
     exit 78
   fi
   set -a; source "$ROOT/.env.container"; set +a
   : "${HLS_CONTAINER_RUN_CMD:?HLS_CONTAINER_RUN_CMD is not set}"
   : "${HLS_CONTAINER_WORKDIR:=/workspace}"
   # Make the src-layout package importable inside a fresh/ephemeral container
   # even when `pip install -e .` was not run in this invocation.
   # HLS_CONTAINER_WORKDIR is the in-container mount point of the repo.
   export PYTHONPATH="$HLS_CONTAINER_WORKDIR/src${PYTHONPATH:+:$PYTHONPATH}"
   # All generated artifacts default under the data disk (AGENTS.md §3).
   export HLS_ARTIFACTS_ROOT="${HLS_ARTIFACTS_ROOT:-/data-20T/hybrid-lidar-sim/artifacts}"
   # `hls ...` works even when the console script was not installed in this
   # (possibly ephemeral) container: route it through the module entrypoint.
   if [[ "${1:-}" == "hls" ]]; then
     shift
     set -- python -m hls.cli "$@"
   fi
   read -r -a CMD <<< "$HLS_CONTAINER_RUN_CMD"
   exec "${CMD[@]}" "$@"
   ```
   It must refuse when the variable is empty and must not hardcode an image. `PYTHONPATH` must use the **in-container** repo path (`HLS_CONTAINER_WORKDIR`, default `/workspace`), never the host path. The `hls` shim is required so `hls version` and every later `hls <command>` invocation works without relying on an editable install. `PYTHONPATH` and `HLS_ARTIFACTS_ROOT` are exported into the container process environment (`docker run` passes the parent environment only with `-e`; the run command recorded in Task 1 MUST include `-e PYTHONPATH -e HLS_ARTIFACTS_ROOT`, or the approved image MUST run `pip install -e .` at build time). Record which of the two applies in the execution contract as `python_env`.

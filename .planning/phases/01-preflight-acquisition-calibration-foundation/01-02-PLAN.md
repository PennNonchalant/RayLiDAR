1. `src/hls/data/preflight.py`:
   - `@dataclass PreflightReport` with `schema_version: int = 1`, `root: str`, `sequence: str`,
     `layout: str`, `components: list[ComponentStatus]`, `inventory: dict`, `external_scans: dict`, `ok: bool`,
     `blocking_missing: list[str]`, `nonblocking_missing: list[str]`, `nonblocking_rejected: list[str]`, `rejected: list[str]`, `generated_at_utc: str`.
   - `run_preflight(root, sequence, cameras, forbidden_names, scan_roots: Sequence[Path] = ()) -> PreflightReport` loads `configs/dataset.yaml` values through the caller; it must not hardcode the root. When `scan_roots` is non-empty, run `find_rejected_calibration` on each root and record `{str(root): [rejected names]}` in `external_scans`; this baseline proves real KITTI-raw calibration files are rejected even though the canonical root is empty.
   - Blocking components: `calibration`, `poses`, `semantics`. Non-blocking: `images`, `lidar`.
   - `ok` is true only when every component is present, has no rejected entries, file counts are positive, and the boolean `components` all pass.
   - `inventory` includes every sequence directory observed under `data_2d_raw`, `data_poses`, and `data_3d_raw`, sorted, so extra sequences are visible but never installed by this command.
   - `preflight_exit_code(report, *, strict: bool = False) -> int`:
     `0` ok; `2` any blocking component missing/rejected, or (when `strict`) any non-blocking component missing/rejected; `3` only non-blocking components missing **or rejected** (e.g., wrong-size image, malformed LiDAR) with `strict=False`; `4` invalid root/config (not a directory, unreadable YAML).
     Blocking takes precedence over non-blocking. A rejected non-blocking component always produces a non-zero exit (never exit 0).
   - `render_summary(report) -> str`: fixed-width table with `COMPONENT`, `STATUS`, `FILES`, `BYTES`, `MISSING`, plus a `REJECTED` section naming KITTI-raw calibration files, rejected non-blocking files, and external scan results.

   - `run(args)` resolves config, calls `run_preflight` with the resolved scan roots, prints `render_summary`, optionally writes JSON with `write_json`, and returns `preflight_exit_code(report, strict=args.strict)`.
   - `--strict` escalates missing or rejected images/lidar to exit 2.

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-02 | Spoofing | `calibration/` validation | mitigate | Exact official filename allowlist; KITTI-raw names are detected recursively and placed in `rejected`; a rejected calibration forces exit 2 |

| T-1-11 | Information Disclosure | Report contents | accept | The report contains only local file paths and counts, no PII or secrets; paths are expected to be local |

  <action>
Implement `src/hls/data/overlay.py` with these exact public functions.

1. `@dataclass(frozen=True) class ProjectionResult`:
   fields `uv: np.ndarray` (N,2 float64), `z: np.ndarray` (N,), `range_m: np.ndarray` (N,), `valid: np.ndarray` (N,) bool, `source_index: np.ndarray` (N,) int.
2. `project_points_V(points_V: np.ndarray, T_Ck_rect_V: np.ndarray, K: np.ndarray, image_size: tuple[int, int], *, min_range_m: float | None = 10.0, max_range_m: float | None = 30.0, margin_px: int = 5) -> ProjectionResult`:
   - Accept `(N,3)` or `(N,4)`; use `xyz = points_V[:, :3].astype(np.float64)`.
   - Homogeneous transform: `p_C = (T @ [x,y,z,1])[:3]`.
   - Valid iff all finite, `z > 0`, `min_range_m <= ||p_C|| <= max_range_m`, and `u,v` inside `[margin_px, W-1-margin_px]` × `[margin_px, H-1-margin_px]`.
   - `u = K[0,0]*x/z + K[0,2]`, `v = K[1,1]*y/z + K[1,2]`. Do not use `K[0,1]`/`K[1,0]` (KITTI perspective K has zero skew).
   - Return arrays in input order; `valid` is the mask. `source_index` is `arange(N)`.
3. `render_overlay(image: Image.Image, result: ProjectionResult, *, scale: int = 1, radius: int = 1, grid_px: int = 80) -> Image.Image`:
   - Convert to RGB. Draw a 1-px light grid every `grid_px` pixels for visual reference.
   - Draw valid points as `radius`-px squares coloured by range: near (10 m) cyan → far (30 m) magenta, using a simple linear RGB interpolation implemented with NumPy; no matplotlib.
   - Resize with `Image.Resampling.NEAREST` by `scale`.
   - If no valid points, still return the gridded image.
4. `edge_distance_score(gray: np.ndarray, result: ProjectionResult, *, discontinuity_m: float = 0.5, neighbour_px: float = 3.0) -> dict`:
   - `gray` is a 2-D uint8/float array with the same `(H,W)` as the image.
   - Compute `mag = hypot(np.gradient(gray, axis=1), np.gradient(gray, axis=0))`; `edges = mag > np.percentile(mag, 90)`; `dist = scipy.ndimage.distance_transform_edt(~edges)`.
   - Use `scipy.spatial.cKDTree` on valid `uv` to find neighbours within `neighbour_px`. Mark a point as a discontinuity candidate if any neighbour's `|z_i - z_j| > discontinuity_m`.
   - If fewer than 50 discontinuity candidates, use all valid points and set `fallback_all_points: true`; otherwise use candidates.
   - Sample `dist[round(v), round(u)]` with bounds checks. Return `{"median_px": float, "p90_px": float, "count": int, "fraction_within_2px": float, "fallback_all_points": bool}`. Use `NaN` for empty input; never raise.
   - This score is advisory. Do not encode the `< 2 px` pass/fail here.
5. `overlay_frame(image_path: Path, points_V: np.ndarray, T_Ck_rect_V: np.ndarray, K: np.ndarray, out_dir: Path, *, scale: int = 4, min_range_m: float = 10.0, max_range_m: float = 30.0, margin_px: int = 5) -> dict`:
   - Open the image; enforce `width * height <= 50_000_000` or raise `ValueError("image too large")`.
   - Project, render 1× and 4×. Write `overlay_1x.png` and `overlay_4x.png`.
   - For the 4× crop, compute the bounding box of valid points in the 1× image, pad 40 px, clamp to image bounds, crop, then resize 4× nearest; if there are no valid points, use the full image.
   - Run `edge_distance_score` on the grayscale 1× image.
   - Return a dict with `image`, `image_size`, `scale_factor`, `points_total`, `points_valid`, `projected_bbox`, `overlay_1x`, `overlay_4x`, and the score fields.

6. Tests in `tests/data/test_overlay.py`:
   - Build a synthetic `K` with `fx=fy=700`, `cx=704`, `cy=188`; identity camera transform; points at `z=10..30` projecting to known integer pixels; assert `uv` error `< 1e-9` and range equals `z`.
   - `z <= 0` points are invalid.
   - Points projecting within 5 px of the border are invalid.
   - Points outside 10–30 m are invalid; with `min_range_m=None, max_range_m=None`, they are valid.
   - Render an image with a black rectangle on white; points along the rectangle edge produce `median_px <= 1.5`.
   - Two depth clusters near an edge produce a lower score than the same points far from edges.
   - Empty input returns `NaN` and `count == 0` without raising.
   - An image over 50 megapixels is rejected before allocation.
